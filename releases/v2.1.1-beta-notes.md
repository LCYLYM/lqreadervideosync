# Reader Sync By Fish v2.1.1-beta

这是用于快速反馈的 beta 版本，核心目标是把用户遇到的卡住、加载中、检测中等问题变成可直接提交的证据包。

## 新增

- 播放器顶部新增“导出日志反馈”按钮。
- 支持填写可选问题描述。
- 支持可选截取当前标签页截图。
- 确认后自动生成 ZIP 反馈包，并打开飞书反馈表单。

## 反馈包内容

- `logs/reader-sync-runtime-logs.json`：结构化运行日志，包含 info/debug/warn/error。
- `logs/reader-sync-runtime-logs.txt`：便于人工阅读的文本日志。
- `feedback/feedback.json`：插件版本、reader 绑定、运行时状态和反馈内容。
- `feedback/feedback.txt`：简要反馈说明。
- `screenshot/current-tab.png`：用户勾选截图时包含。

## 修复与验证

- 日志收集覆盖 player、content script、background service worker。
- 下载使用 Chrome downloads API 生成真实 ZIP 文件。

- 已用有头 Chromium 验证导出 ZIP、截图、打开表单链路。

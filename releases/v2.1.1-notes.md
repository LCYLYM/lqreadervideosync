# Reader Sync By Fish v2.1.1

## 亮点

- 播放器页改为两步向导：先选择字幕来源，再拖入视频文件，完成后进入极简播放器。
- 默认自动绑定唯一打开的 aim-read 阅读页，不再让用户手动选择绑定页面。
- 内置 Friends S01-S10 本地字幕包，支持根据 reader 页面标题、正文和剧集信息自动匹配字幕。
- 保留手动拖入 ASS、SSA、SRT、VTT 字幕文件的真实解析和运行时匹配流程。
- 视频导入只接受 MP4 / MKV，并继续使用浏览器内 FFmpeg 做真实容器、视频流、音频流检测。
- 非推荐基线视频默认走“一键处理并播放”；忽略风险播放会先弹出风险确认。
- 新增日间、夜间、跟随浏览器三种主题模式，并同步到 reader 页面浮窗。
- 修复 A4 竖版、窄屏、半屏窗口下的向导页和播放器自适应问题。
- 修复切换下一集后旧视频仍在后台播放的问题。
- 优化 MV3 端口重连和非文章页快照采集日志，减少误导性控制台 warn。

## 包含内容

- 浏览器扩展安装包 ZIP
- 源码快照 ZIP
- 内置 Friends S01-S10 字幕资源与构建生成的字幕索引

## 验证

- `pnpm run check`
- `pnpm run build`
- `pnpm run smoke:preprocess`
- A4 竖屏、窄屏、半屏尺寸下的真实 Chromium 布局检查

## 说明

- 在线匹配入口仍为“敬请期待”，本版本不访问 GitHub 远程字幕仓库。
- 本地视频处理仍在浏览器本地完成，不上传用户视频。
- 运行时同步仍依赖真实 aim-read 阅读页和真实文章快照。
- 公开发布内容已排除本地登录态、测试媒体、临时输出和私有缓存。

# Reader Sync By 🐟 v0.1.9

## 亮点

- 修复浏览器内 FFmpeg 预处理进度到 100% 后仍停在“重封装为 MP4”状态的问题
- 预处理完成态现在以真实输出文件读回为准：编码结束后会进入封口与读取阶段，只有生成可播放 MP4 后才显示 100% 并释放播放/下载按钮
- 修复大文件输出 Blob 构造边界，避免浏览器内存文件系统读回后生成异常对象 URL
- 增加有头浏览器预处理 smoke：真实加载扩展、检测 MKV、执行本地预处理并确认转码版视频已加载
- 同步文章快照接口抓取的分页回退策略，降低大页请求失败时整页同步失败的概率

## 包含内容

- 浏览器扩展安装包 ZIP
- 源码快照 ZIP

## 验证

- `pnpm run check`
- `pnpm run build`
- `pnpm run smoke:preprocess -- --timeout-ms 300000`

## 说明

- 运行时匹配仍依赖真实的 `aim-read` 页面与文章接口
- 本地视频与字幕处理仍完全在浏览器本地进行
- 公开发布内容已排除本地登录态、测试媒体和私有工作区痕迹
